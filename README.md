# 🎙 HoldToTalk

Голосовой ввод для macOS: **зажмите клавишу, говорите, отпустите** — и распознанный текст сам вставится туда, где стоит курсор (в любом приложении: браузер, Telegram, Notes, VS Code…).

- Клавишу выбираете сами: правый ⌥ Option (по умолчанию), правый ⌘, Fn, F13… или любую другую через «Назначить другую клавишу».
- Русский, английский и все остальные языки, которые поддерживает macOS.
- Распознавание встроенное в macOS (Apple Speech), работает офлайн на Mac с Apple Silicon. Без ключей API и подписок.
- Живет в строке меню, во время записи показывает окошко с распознаваемым текстом.

## Установка

1. Откройте [**Releases**](../../releases/latest) и скачайте `HoldToTalk.zip`.
2. Распакуйте и перетащите **HoldToTalk.app** в папку **Программы**.
3. Приложение не подписано платным сертификатом Apple, поэтому при первом запуске macOS его заблокирует. Самый простой способ — выполнить в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/HoldToTalk.app
   ```
   Или: попробуйте открыть приложение → **Системные настройки → Конфиденциальность и безопасность** → внизу «Всё равно открыть».
4. Запустите HoldToTalk. В строке меню появится значок 🎙.

## Разрешения

При первом запуске откроется окно настроек. Нужно разрешить три вещи:

| Разрешение | Зачем |
|---|---|
| **Микрофон** | слушать вас, пока клавиша зажата |
| **Распознавание речи** | превращать голос в текст |
| **Универсальный доступ** | замечать нажатие клавиши в любом приложении и вставлять текст |

Универсальный доступ включается вручную: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → HoldToTalk**. Когда все три пункта зелёные, значок в меню станет обычным 🎙 (перечёркнутый — значит, чего-то не хватает).

## Как пользоваться

1. Поставьте курсор в любое текстовое поле.
2. Зажмите выбранную клавишу (по умолчанию — **правый ⌥ Option**) и говорите.
3. Отпустите — текст вставится.

Советы:
- Если зажать модификатор и нажать другую клавишу (например ⌥+E), диктовка отменится — сочетания клавиш продолжают работать.
- Очень короткое нажатие (меньше 0,3 с) игнорируется.
- Клавиша **Fn / 🌐**: чтобы macOS не открывала по ней эмодзи или системную диктовку, поставьте в *Настройки → Клавиатура → «При нажатии клавиши 🌐»* значение «Ничего не делать».
- Верхний ряд MacBook (яркость, громкость) по умолчанию шлёт медиа-команды, а не F1–F12 — их назначить нельзя. Лучше использовать модификаторы.
- Офлайн-распознавание: *Системные настройки → Клавиатура → Диктовка* — включите и выберите язык, чтобы macOS скачала модель. Без неё распознавание идёт через серверы Apple.

## Если после обновления клавиша перестала работать

Новая версия приложения для macOS — «другое» приложение. Удалите HoldToTalk из списка «Универсальный доступ» кнопкой «–» и добавьте/включите заново.

## Сборка из исходников

Нужны Xcode Command Line Tools (`xcode-select --install`).

```bash
scripts/build_app.sh
```

Готовое приложение появится в `build/HoldToTalk.app`. Новый релиз на GitHub собирается автоматически при пуше тега `v*`:

```bash
git tag v1.0.1 && git push origin v1.0.1
```
